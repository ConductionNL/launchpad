# EspoCRM Cloud & Pricing

**Source:** https://www.espocrm.com/cloud/ and https://www.espocrm.com/extensions/
**Fetched:** 2026-03-14

## Deployment Options

### Self-Hosted (Free)
- Download and install on own server
- Supports Apache, Nginx, IIS
- Docker support with official images (Traefik, Caddy)
- PHP 8.x + MySQL/MariaDB/PostgreSQL
- User responsible for upgrades, backups, security
- Extensions purchased separately

### Cloud (Managed)
- Hosted by EspoCRM team
- Server locations: United States and Germany
- All extensions included at no extra cost
- Automatic upgrades
- Daily backups (7-day retention)
- SSL encryption (256-bit keys, TLS 1.3)

## Cloud Pricing

| Plan | Price | Min Users | Min Monthly Cost | Storage | Records | Support |
|------|-------|-----------|-----------------|---------|---------|---------|
| Basic | $15/user/month | 3 | $45/month | 3GB/user | 100,000 | 12x5 email |
| Enterprise | $25/user/month | 5 | $125/month | 7GB/user | 1,000,000 | 12x5 email |
| Ultimate | $69/user/month | 10 | $690/month | 400GB total | Unlimited | 12x5 email |

### Billing Details
- Basic and Enterprise: Billed 6 months or 1 year
- Users can be added and charged per month
- Enterprise record limits can be extended for additional fee
- Ultimate: Dedicated IP, private server, own domain name

### Storage
- Basic: 3GB per user (total = users x 3GB)
- Enterprise: 7GB per user (total = users x 7GB)
- Ultimate: 400GB total (shared)
- Additional storage: Purchase extra user licenses to increase total

### What's Included (all plans)
- Full feature set
- All extensions (Advanced Pack, Sales Pack, Project Management, VoIP, etc.)
- 2000+ integrations via Zapier/Make
- 30-day free trial

## Competitive Pricing Context

For a team of 10 users:
- **EspoCRM Cloud Enterprise:** $250/month ($3,000/year)
- **EspoCRM Self-Hosted + All Extensions:** $0 + $2,298/year
- **EspoCRM Self-Hosted (core only):** $0

**Pipelinq advantage:** Included with Nextcloud at no additional cost; no per-user pricing for pipeline features. Organizations already running Nextcloud get pipeline management as part of the platform.
