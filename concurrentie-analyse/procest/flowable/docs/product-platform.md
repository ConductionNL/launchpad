# Flowable Platform Documentation

Source: https://www.flowable.com/product/platform

## Product Vision

"Business automation that holds when reality deviates."

Traditional automation assumes work follows a predefined path. Flowable is built for reality where exceptions, judgment, and change are the norm. It is the top agentic process automation and orchestration platform designed for process-intensive, compliance-driven organizations.

## Platform Components

### 1. End-to-end Business Orchestration
Coordinate agents, people, and processes across systems with agentic AI. Bring AI agents into the orchestration mix with trust, visibility, and real-time adaptability.

### 2. Agentic AI
AI agents embedded within case and process automation. Multiple agent types:
- Orchestrator agents (CMMN-embedded)
- Knowledge agents (RAG-based)
- Document agents (classification/extraction)
- Utility agents (tool-based)
- A2A agents (agent-to-agent)
- External agents (Azure, AWS, Salesforce)

### 3. Enterprise Connectivity
Integration and connector framework for databases, RESTful data sources, and enterprise systems.

### 4. Case Management
Dynamic case management built on CMMN standard. Human-centric approach for complex, unpredictable workflows.

### 5. Content Management
Enterprise Content Management capabilities for document and unstructured data processing.

### 6. Intuitive Modeling (Flowable Design)
Drag-and-drop visual modeling for BPMN, CMMN, DMN. Visual expression builders and variable autocompletion. Free cloud-based designer available for open-source users.

### 7. Process Monitoring & Optimization (Flowable Control)
Runtime engine monitoring, analysis, and downloadable reports. Visual test and debug with Inspect.

## Key Value Propositions

1. **Enable people and AI**: Harness agentic process automation and human capability
2. **True end-to-end orchestration**: Eliminate silos, connect everything
3. **AI-powered automation**: LLM integration for repetitive tasks
4. **Scale enterprise wide**: Department to global rollout
5. **Guardrail autonomous AI**: Compliance and accountability
6. **Customer satisfaction**: Faster, consistent experiences
7. **Futureproof**: A2A architecture, centralized MCP, multi-agent orchestration
