# Project Management

## Overview

EspoCRM offers a **Project Management** extension ($230/year, included in cloud plans) that adds project tracking capabilities to the CRM. This is relevant to Pipelinq because it provides kanban boards, task management, and Gantt charts - features that overlap with pipeline management.

## Features

### Projects
- Project entity with name, status, dates, budget
- Link projects to Accounts, Contacts, Opportunities
- Project status tracking (Not Started, Started, Completed, etc.)

### Tasks
- Task entity with assignee, status, priority, dates
- Tasks linked to projects and milestones
- Task dependencies

### Milestones
- Milestone markers within projects
- Due date tracking
- Progress indicators

### Kanban Boards
- Visual task boards with drag-and-drop
- Column-based status view
- Per-user card ordering

### Gantt Chart
- Timeline visualization of tasks and milestones
- Task dependency arrows
- Date range filtering

## Strengths

- Integrated with CRM data (link projects to deals/accounts)
- Kanban + Gantt in one package
- Task dependencies
- Milestone tracking

## Weaknesses

- Paid extension ($230/year for self-hosted)
- Basic compared to dedicated PM tools (no resource management, time tracking, or sprint planning)
- No collaborative editing
- No template projects
- Limited Gantt interactions
