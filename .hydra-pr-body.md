## Summary

Implements the `dashboard-switcher-sidebar` openspec change (REQ-SWITCH-001..007): a fixed-position slide-in left navigation panel that lists every dashboard visible to the user, grouped into three labelled sections in fixed order (primary group → default group → personal). The components (`DashboardSwitcherSidebar.vue`, `SidebarBackdrop.vue`, `SidebarFooter.vue`) and their Vitest + Playwright test coverage were already present on the development branch (wave3.x evolution). This PR records the spec artefacts (`design.md`, updated `tasks.md`, corrected `spec.md`) and fixes a stale URL assertion in `SidebarFooter.spec.js` (expected `https://launchpad.conduction.nl` but `DOCS_URL` was updated to `https://launchpad.conduction.nl/docs/intro`).

All 857 Vitest tests pass. ESLint: 0 errors, pre-existing warnings only.
