## Gemeente Utrecht

### Overview
Utrecht is the largest publicly known deployment of xxllnc Zaken and represents a major reference case.

### Scale
- **750 zaaktypen** (case types)
- **8 million+ cases** (open and closed)
- **2,300+ users**

### Context
The municipality was previously using the Exxellence Suite (predecessor product). The transition to xxllnc Zaken was described as an intermediate step ("tussenstap") toward further modernization of the information landscape following Common Ground principles.

### Key Takeaways
- The case system functions as a central hub ("spin in het web") connecting numerous information sources
- Demonstrates platform scalability for large municipalities
- Migration from legacy systems within the same vendor ecosystem
- Common Ground adoption as a strategic direction

## Gemeente Epe

### Overview
Epe was one of the very first customers of xxllnc Zaken (then Zaaksysteem.nl), starting in 2014.

### Scale
- **~200 zaaktypen** (case types)
- Small/medium municipality

### Implementation Journey
- Decision to switch to case-oriented working in 2014
- Solution had to be built, coupled, and configured from scratch
- Deadline: social domain processes in the system before January 1, 2015
- Over 2-3 years, approximately 200 case types were gradually added
- Achieved an "xxllnc Zaken, unless..." policy — case management as default solution

### Benefits Realized
- Decommissioned several back-office systems
- Saved numerous software licenses
- Fully digital processes based on 200 case types
- Citizens use Personal Internet Page (PIP) for self-service:
  - Track permit status (e.g., tree cutting permits)
  - Check report processing status (e.g., street furniture)
  - Access relevant personal information

### Key Takeaways
- Demonstrates suitability for small/medium municipalities
- Gradual rollout approach (2-3 year timeline)
- System consolidation leading to cost savings
- Citizen self-service via PIP portal

## Implementation Process

xxllnc describes a 6-step implementation process:

### Step 1: Framework Sessions
Determine system setup including:
- Archiving structure
- Roles and permissions model
- Foundation for the implementation

### Step 2-5: Configuration and Setup
- Case type configuration
- Process design
- Integration setup
- Template creation

### Step 6: Go-Live
- User training
- Support setup via mijn.xxllnc portal

### Timeline Factors
Implementation duration varies based on:
- **Maturity level** of case-oriented working in the organization
- **Number of processes** to be specifically configured
- **Number of integrations** needed with existing systems
- Range: **3 months to 3 years**
