## License

**AGPL-3.0** (GNU Affero General Public License v3.0)

This means:
- Free to use, modify, and distribute
- Source code must be made available if hosting a modified version
- Network use counts as distribution (AGPL clause)
- Any derivative work must also be AGPL-licensed

## Pricing Tiers

### Self-Hosted (Free)
- **Cost:** $0
- **Contacts:** Unlimited
- **Features:** Full feature set, no restrictions
- **Requirements:** Own server with PHP 8.3+, MariaDB/MySQL, Redis
- **Support:** Community only (GitHub issues)

### Hosted Free Plan
- **Cost:** $0
- **Contacts:** 10 contacts maximum
- **Features:** Some features restricted (not specified which)
- **URL:** app.monicahq.com

### Hosted Paid Plan
- **Cost:** $9/month or $90/year (2 months free on annual)
- **Contacts:** Unlimited
- **Reminders:** Unlimited
- **Features:** Full feature set
- **Pricing model:** Flat pricing, no per-contact fees
- **URL:** app.monicahq.com

## Cancellation Policy

- Cancel anytime, no commitments
- No cancellation fees
- Access continues until end of billing period
- Account retained (can reactivate later)

## Refund Policy

Available at monicahq.com/refund (details not analyzed).

## Revenue Model

- Hosted subscriptions
- Patreon donations
- No ads, no data selling, no tracking

## Comparison Notes for Pipelinq

Monica's pricing is simple and individual-focused. Key observations:
1. No team/organization tiers
2. No per-seat pricing — single user per subscription
3. Self-hosting removes all revenue for the project
4. The AGPL license prevents commercial forks without source disclosure
5. No enterprise features or pricing
6. No API-only plans
