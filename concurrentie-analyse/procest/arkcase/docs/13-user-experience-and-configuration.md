# ArkCase User Experience and Configuration

**Source:** arkcase.com/your-arkcase-experience/

## Configuration Model

The configuration, customization, and permissions chosen affect:
- What users see
- What options are available
- How cases move through workflows

Each organization configures and customizes ArkCase to their business requirements. Configuration transforms the out-of-the-box (OOTB) ArkCase application by specifying:
- Use of modules (activate/deactivate)
- Automated review and approval workflows
- Access roles and permissions
- Parameters for reporting and audit

## Workflow System

Workflows ensure cases and complaints are consistently and correctly handled through a precise set of steps:
- Workflows perform automatic steps defined by the organization
- Workflows are business-based, supporting background processes
- Pre-defined business events trigger next steps

**Example flow:** Originator submits a new case request -> automated task is routed to reviewer/approver -> copy sent to folder. Same procedure for every new case.

Benefits over manual processes:
- No separate document preparation for review
- No attaching and mailing to distribution lists
- No manual due date follow-up

## Roles and Permissions (RBAC)

Navigation and viewing is based on Role-Based Access Control:
- **Role** determines content access and available actions
- **User groups** aggregate users with similar permissions
- Each user may belong to multiple groups
- Roles and groups together control the full user experience
