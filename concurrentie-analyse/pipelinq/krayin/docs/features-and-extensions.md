# Krayin CRM - Features & Extensions

## Core Features (Free, MIT License)

### Sales Management
- **Lead tracking** with visual Kanban pipeline
- **Multiple pipelines** with configurable stages and probability percentages
- **Rotten lead detection** - highlights stale leads based on configurable inactivity threshold
- **Deal value tracking** with expected close dates
- **Lead sources and types** for categorization
- **Win/loss tracking** with lost reasons

### Contact Management
- **Persons** (individuals) with emails, phone numbers, custom fields
- **Organizations** linked to persons
- **Export** to XLS/CSV formats

### Activity Tracking
- Call, meeting, lunch, note, email, file types
- Calendar view with day/week/month
- Participant tracking (internal users + external contacts)
- File attachments per activity

### Email Integration
- Built-in email client (inbox, outbox, draft, trash)
- IMAP polling (Webklex-IMAP)
- SendGrid Inbound Parse webhook
- Email-lead linking for conversation tracking

### Quoting
- Quote generation with line items
- Per-line discounts, taxes
- Billing/shipping addresses
- Printable quote output
- Quote-lead linking

### Product Catalog
- Products with SKU, pricing, inventory
- Warehouse/location management
- Product-lead relationship with per-deal pricing

### Automation
- Workflow rules with conditions and actions
- Webhooks for outbound HTTP notifications
- Event-based email campaigns

### Data Management
- CSV/XLSX import with validation and preview
- Queue-based processing for large datasets
- Sample template downloads
- Error reporting

### Access Control
- Role-based access control (RBAC)
- User groups
- Per-entity CRUD permissions
- Data-level access via bouncer

### Custom Attributes
- Unlimited custom fields on all entities
- Multiple field types (text, select, date, file, etc.)
- EAV (Entity-Attribute-Value) storage

### Web Forms
- Embeddable lead capture forms
- Custom field inclusion
- Automatic lead creation from submissions

### AI Features
- AI-powered lead creation from document uploads (PDF, images)
- OpenRouter AI integration
- Structured data extraction

### Dashboard
- Leads over time, revenue stats
- Top leads, top customers, top products
- Pipeline stage distribution
- Activity breakdown

### Multi-language
- English, Turkish, Arabic built-in
