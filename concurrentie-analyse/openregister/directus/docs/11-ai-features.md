# Directus AI Features

**Source:** https://docs.directus.io/guides/ai/

## Overview

Directus offers two AI integration approaches:

## 1. Built-in AI Assistant
Conversational assistant directly within the Data Studio.
- Works directly in the Directus UI
- No additional client setup required
- Best for content editors, quick tasks, and users who work in Directus
- Configurable AI model providers

## 2. MCP Server (Model Context Protocol)
Lets external AI tools connect to Directus.
- Compatible with Claude Desktop, ChatGPT, Cursor, and other MCP clients
- Brings Directus capabilities to external tools
- Best for developers, power users, and complex workflows
- Includes tools, prompts, and security configuration
- Local MCP server option available

### MCP Features
- Installation and configuration guides
- Use case documentation
- Custom tools
- Custom prompts
- Troubleshooting
- Security considerations

## Comparison Notes (vs OpenRegister)

| Aspect | Directus | OpenRegister |
|--------|----------|-------------|
| AI Assistant | Built-in Data Studio assistant | Not available |
| MCP Server | Official MCP server | Custom MCP implementation (standard protocol) |
| AI Integration | First-class feature | MCP endpoint (basic) |
| LLM Providers | Configurable | Not configurable |
| AI for Content | Built-in editing assistance | Not available |
