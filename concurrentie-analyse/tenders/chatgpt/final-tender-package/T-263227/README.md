## Context en scope

Deze offerteaanvraag betreft de aanbesteding van een nieuw zaaksysteem voor de gemeente Waterland. Het huidige zaaksysteem wordt vanaf 1 juli 2023 niet meer ondersteund.

Relevantie voor productlijn: procest.

In de stukken worden minimaal 9 integraties of standaarden genoemd, waaronder KVK, digid, eherkenning, eidas, STUF, API.
