## Context en scope

Vanuit het Shared Service Center ONS (SSC-ONS) wordt de aanbesteding voor een nieuw 
zaaksysteem uitgevoerd voor drie van de deelnemende partners, te weten de gemeenten Dalfsen, 
Zwartewaterland en Westerveld.
