## Context en scope

Door de komst van de Omgevingswet zal bestaande applicatie vervangen (moeten) worden door een nieuw, modern VTH-systeem, dat klaar is voor de toekomst.

Relevantie voor productlijn: procest.

In de stukken worden minimaal 11 integraties of standaarden genoemd, waaronder BRP, BAG, KVK, digid, STUF, ZGW.

Een deel van de bronset is scan-gebaseerd; voor 4 documenten is OCR ingezet in deze herstelronde.
