# Pricing Model

## What It Is

Flowable uses a tiered pricing model with three levels: Community (free), Platform (commercial), and Agentic Case Platform (commercial). Pricing is based on users, running case/process instances (RCPI), and agent packages.

## Pricing Structure

### Community Edition
- **Cost**: Free (Apache 2.0)
- **Includes**: BPMN, CMMN, DMN engines only
- **Support**: Community forum only
- **Limitations**: No HA, no UI, no low-code, no reporting, no content management

### Flowable Platform
- **Cost**: Contact sales (no public pricing)
- **Pricing model**: Users + RCPI (Running Case & Process Instances) packages
- **Includes**: Work + Design + Control applications
- **Support**: Silver/Gold/Platinum SLA tiers

### Agentic Case Platform
- **Cost**: Contact sales (no public pricing)
- **Pricing model**: Users + RCPI + Agent packages
- **Includes**: Everything in Platform + AI Studio + all agent types
- **Support**: Silver/Gold/Platinum SLA tiers

## Deployment Options

1. **Customer Managed** - on-premise or own cloud infrastructure
2. **Flowable Cloud Shared** - multi-tenant cloud
3. **Flowable Cloud Dedicated** - single-tenant cloud

## Market Positioning

Flowable targets enterprise organizations:
- 600+ enterprise customers
- Focus on banking, insurance, healthcare, manufacturing
- Gartner Magic Quadrant recognition
- Reviews on Capterra, G2, Gartner Peer Insights

## Relevance to Procest

### Competitive Advantages for Procest
- **Transparent pricing**: Procest can offer clear, public pricing
- **No lock-in**: Full functionality in open-source (vs Flowable's open-core)
- **Lower TCO**: Nextcloud hosting vs dedicated Java infrastructure
- **Government-friendly**: Per-organization pricing vs per-user
- **Self-hosted**: No cloud dependency required

### Lessons from Flowable's Model
- RCPI-based pricing aligns costs with actual usage
- Tiered support SLAs are expected by enterprise customers
- Free tier (community) drives adoption for commercial conversion
- Training and certification create additional revenue stream
