## Context en scope

Binnen de VRU wordt momenteel gewerkt aan het project Externe Dienstverlening. Dit project heeft tot doel om de informatievoorziening aan externe klanten  (personen en partijen in onze regio met een informatiebehoefte) te professionaliseren. De VRU is voornemens om vanuit dit project een systeem in gebruik te nemen voor de registratie van extern klantcontact.

Wij zijn (nog) niet bekend met deze markt, de mogelijkheden en de spelers, vandaar dat wij graag input ontvangen door middel van deze marktconsultatie.
