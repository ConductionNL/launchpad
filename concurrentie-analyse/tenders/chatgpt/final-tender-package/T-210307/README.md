## Context en scope

Het doel van deze aanbesteding is het afsluiten van een overeenkomst met een leverancier voor het beschikbaar stellen, implementeren, beheren, onderhouden en verder ontwikkelen van een systeem dat zaakgerichtwerken met een geïntegreerd documentmanagementsysteem mogelijk maakt. De oplossing wordt geleverd als Software as a Service (SaaS).

Relevantie voor productlijn: procest.

In de stukken worden minimaal 7 integraties of standaarden genoemd, waaronder BRP, KVK, STUF, ZDS, ZGW, API.
