## Summary

This change adds the `group_shared` third dashboard scope to LaunchPad, enabling admins to author live shared dashboards that render in real-time for every member of a Nextcloud group. Edits propagate immediately on next page load — no per-user copy is created. The `'default'` synthetic group sentinel makes dashboards visible to all users without requiring group membership. A single `/api/dashboards/visible` endpoint unions personal + group + default-group dashboards so the frontend has one source of truth, with each row tagged with a `source` field (`'user'|'group'|'default'`) so the frontend knows which mutation endpoint to call.

The existing `admin_template` capability is intentionally untouched — it keeps its "snapshot copy-on-first-access" meaning and the two scopes coexist.
