## Context en scope

Levering, implementatie en beheer van een SaaS-systeem voor:
- Zaakgericht vergunningbeheer
- Digitaal klantportaal (eHerkenning/eIDAS/basislogin)
- Koppelingen met o.a. KvK, RDW, ERRU, Visma Financials
- Volledige ondersteuning van werkprocessen NIWO
- Ondersteuning rapportages, dashboards, registraties, archivering, klantcontact
