# Directus Insights (Dashboards)

**Source:** https://docs.directus.io/guides/insights/overview.html

## Overview

Insights is a Data Studio module for rapid, no-code analytics dashboard creation. Use cases include:
- Business intelligence
- User progress tracking
- Web traffic conversions
- KPI monitoring
- Custom internal applications

## Dashboards

- Drag-and-drop canvas for creating and arranging panels
- Dashboard area automatically expands as panels are added
- Auto-refresh with configurable intervals
- Create dashboards with name, icon, and color

## Panels

Panels are the building blocks of dashboards:
- Customizable components within dashboards
- Data visualizations from Directus project data
- Can contain interactive elements
- Suitable for building custom internal applications
- Extensible via panel extensions

### Built-in Panel Types
(Based on extension system — panels are a dedicated extension type)
- Data visualization panels
- Metric panels
- Chart panels
- Custom panels via extensions
