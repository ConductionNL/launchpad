# xxllnc Zaken - Product Features Documentation

**Source:** https://xxllnc.nl/applicaties/zaken
**Last fetched:** 2026-03-14

## Tagline

"Zelfstandig bedrijfsprocessen zaakgericht digitaliseren" — Independently digitize business processes in a case-oriented way.

## Core Features

### 1. Slimme Formulieren (Smart Forms)
Intelligent forms including identification and authentication that allow residents and organizations to submit digital requests. Form data is stored directly in the case record. Forms are designed through a zero-coding interface by functional administrators.

### 2. Krachtige Zaakbehandeling (Powerful Case Processing)
Process cases based on custom-configured processes, including:
- Storing information
- Decision trees (vraagbomen)
- Involved parties (betrokkenen)
- Documents
- Archive properties (archiefeigenschappen)

### 3. Uitgebreid Zoeken (Advanced Search)
Search and create overviews using filters for case information:
- List view display
- Map-based views (kaartlagen)
- Save and share overviews
- Use overviews in dashboard widgets

### 4. Veilig Archiveren (Secure Archiving)
Full-fledged archive application (RMA) certified against:
- NEN-ISO 16175-1:2020 (formerly NEN-2082)
- Records management standards

### 5. Zelf Beheren (Self-Management)
Zero-coding administration portal:
- Design forms
- Configure processes
- Use templates
- Add users and authorizations without limit
- Add integrations to processes
- No technical consequences for configuration changes

### 6. Omgeving voor Inwoners — PIP (Citizen Portal)
Personal Internet Page (PIP) for residents and organizations:
- Digital transactions with the organization
- Document publishing
- Message exchange
- 24/7 case status visibility
- Custom branding (huisstijl)

## Full Feature List

As listed on the product page:
- Intuitive interface
- User-friendly dashboard with self-configurable widgets
- Responsive design (computer, tablet, phone)
- Quick case information search with various search functionalities
- Extensive communication module for incoming and outgoing messages
- Document creation based on templates

## Additional Modules

### Documentwatcher
Synchronize documents from local workstations with case file documents. Supports local office documents and other file formats supported by the case system.

### Anonimiseren (Anonymization)
Anonymize documents directly from the case system via Datamask integration. All actions performed from within the case system.

### Ondertekenen (Digital Signing)
Sign documents legally and directly from the case processing screen via Zynyo or ValidSign integration.

## Microsoft Teams Integration
Available on the Microsoft Marketplace (WA200009114):
- Open and edit case files directly within Microsoft Teams
- Synchronize after editing
- Start new cases from a Teams channel
- Supports Microsoft 365 document formats (Word, Excel, PowerPoint)

## Implementation

The xxllnc implementation process follows 6 steps:
1. Framework sessions — determine system setup (archiving, roles, permissions)
2. Configuration of case types
3. Process design
4. Integration setup
5. User training
6. Go-live and support

Timeline varies from 3 months to 3 years depending on:
- Level of case-oriented working maturity
- Number of processes to configure
- Number of integrations required
