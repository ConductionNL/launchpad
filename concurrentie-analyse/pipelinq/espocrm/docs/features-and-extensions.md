# EspoCRM Features and Extensions

**Source:** https://www.espocrm.com/features/ and https://www.espocrm.com/extensions/
**Fetched:** 2026-03-14

## Core Features (Free, Open Source)

### Sales Essentials
- **Leads** - Potential customers; capture via web forms or API (Web-to-Lead)
- **Opportunities** - Potential sales deals with stage-based pipeline (Prospecting > Qualification > Proposal > Negotiation > Closed Won/Lost), probability percentages per stage
- **Accounts** - Organizations / central records
- **Contacts** - Individuals your business works with

### Calendar
- **Calendar** - Meetings, calls, and tasks; shared calendar views
- **Working time calendar** - Manage work schedules

### Emails
- **Email accounts** - Fetch emails from IMAP mailboxes into CRM
- **Email sending** - Compose and send emails from CRM via SMTP
- **Email templates** - Craft and organize reusable emails with placeholders
- **Mass email** - Send emails in bulk to target lists

### Social
- **Stream** (Activity feed) - Feed that keeps you informed of record changes and updates

### Customer Support
- **Cases** - Track and manage customer issues/tickets
- **Portal** - Customer-facing access point (self-service)
- **Knowledge base** - Help center for customers and staff

### Documents
- **Documents** - Upload and organize documents within CRM records

### Marketing
- **Web-to-Lead** - Capture leads via web forms or API
- **Campaigns** - Mass emails, mail merge, tracking (opens/clicks/bounces/opt-outs)

### Customization
- **Entity Manager** - Create custom entities, fields, and relationships (no-code)
- **Dynamic Logic** - Define rules to make forms dynamic (show/hide fields conditionally)
- **Formula** - Write scripts to calculate fields or perform actions
- **Extensions** - Install addons to expand the CRM

### Administration
- **Users** - Employee management with CRM access
- **Teams** - Users organized into teams
- **Roles** - Access control for users and teams (field-level, record-level)

### Import & Export
- **Import** - Bring data from CSV/spreadsheet
- **Print to PDF** - Generate documents from templates with record data
- **Export** - Extract data to spreadsheet or CSV

## Paid Extensions

### Advanced Pack - $395/year
- **Reports** - Consolidated business information with charts and grids
- **Workflows** - Simple automation rules (trigger-action based)
- **BPM (Business Process Management)** - Model and automate processes using BPMN 2.0 visual editor

### Sales Pack - $260/year
- **Products** - Item catalog management
- **Price books** - Differentiated customer pricing
- **Supplier prices** - Vendor rate management
- **Quotes** - Sales proposals
- **Sales orders** - Confirmed customer orders
- **Delivery orders** - Goods issued tracking
- **Return orders** - Handle returned goods
- **Invoices** - Issue invoices for sales
- **Credit notes** - Reduce/correct issued invoices
- **Purchase orders** - Procurement requests
- **Bills** - Supplier invoices
- **Bill credits** - Supplier invoice corrections
- **Receipt orders** - Track received products
- **Payments** - Record and allocate inbound/outbound payments
- **Payment requests** - Create unique payment links
- **Subscriptions** - Automate recurring invoices
- **Multi-currency** - Sell/purchase in multiple currencies; track FX gains/losses
- **Taxes** - Tax calculation and reporting engine with rules
- **Inventory management** - Track and manage stock quantity and location

### Project Management - $230/year

## Licensing Model

- Core: AGPL-3.0 (free, open source)
- Extensions: Per-instance license, 1-year upgrades
- Cloud: All extensions included in all plans
- Self-hosted: Buy extensions separately
