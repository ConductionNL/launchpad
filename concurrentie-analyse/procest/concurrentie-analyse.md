# Procest — Concurrentie-analyse

## Product Description

Procest is a **case management application** (zaakgericht werken) built natively on Nextcloud. It enables government and public sector organizations to process cases (requests, applications, complaints) through defined lifecycle stages with configurable workflows, automatic deadline tracking, task assignment, document checklists, and formal decision recording. Built on CMMN 1.1 and compatible with Dutch ZGW API standards.

## Comparable Software Categories

- Case Management Systems (CMS)
- Business Process Management (BPM) platforms
- Zaakgericht Werken platforms (Dutch government standard)
- Workflow Management / Process Orchestration
- Government Service Delivery platforms
